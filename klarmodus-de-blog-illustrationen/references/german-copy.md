# Deutsche Bildbeschriftungen

Beschrifte die dargestellte Handlung so, wie sie in einem deutschen Blogartikel erklärt würde. Ausgangspunkt ist die Aussage, nicht die Wortfolge einer fremdsprachigen Vorlage.

## Vor der Bilderzeugung

1. Formuliere die Kernaussage in einem deutschen Satz.
2. Benenne nur die Gegenstände und Schritte, die zum Verständnis nötig sind.
3. Lies die Beschriftungen zusammen: Ist der Ablauf ohne den Artikel verständlich?
4. Kürze auf möglichst zwei bis fünf Wörter je Hinweis. Ein einzelnes klares Wort reicht für einen Gegenstand.
5. Lege den genauen Wortlaut für den Bildprompt fest und prüfe ihn im fertigen Bild erneut.

Verwende echte Umlaute und ß. Vermeide abgeschnittene Wörter und künstliche Komposita. Nutze gebräuchliche Begriffe wie Blogartikel, Kundenfragen, Praxisbeispiel, Angebot oder Anfrage. Fachwörter wie KI und Newsletter sind in ihrem passenden Kontext in Ordnung.

## Sinngemäße Formulierungen

| Zu wörtlich oder unklar | Je nach Aussage passend |
| --- | --- |
| Anschluss / Anschlussweg | Nächster Schritt / Vom Artikel zur Anfrage |
| Anschluss-Werkzeugkasten | So geht’s weiter / Passende Handlungsaufforderung |
| Materialkiste / rohes Erfahrungswissen | Ideensammlung / Erfahrungen & Ideen |
| Externe Signale / interne Ressourcen | Markt & Trends / Eigenes Wissen |
| Reichweitenpost / Vertrauenspost | Kurzbeitrag / Praxisbeispiel |
| Idee zu weich | Noch zu vage |
| System trägt | Routine automatisieren |
| Informationsbrunnen | Wissen sammeln |
| Langtexte nicht leer lassen | Substanz statt Fülltext |
| Kernkurs | Hauptangebot; Kurs nur bei einem tatsächlichen Kursthema |

Die Tabelle ist keine feste Ersetzungsliste. „Anschluss“ bleibt etwa bei einer technischen Verbindung richtig. „Conversion“ kann in einem Fachartikel sinnvoll sein; für ein Bild über Kundenanfragen ist „Anfragen“ meist konkreter.

## Aussage und Beispiele

- Metaphern dürfen ungewöhnlich sein. Ihre Beschriftungen müssen auch ohne Kenntnis der Vorlage verständlich bleiben.
- Erfinde keine Kunden, Zitate, Ergebnisse, Preise oder Prozentwerte. Wenn eine Illustration nur Belegtypen erklärt, genügen „Praxisbeispiel“, „Kundenstimme“ oder „Arbeitsprobe“ als Kategorien.
- Übernimm aus Referenzbildern keine beliebigen Fristen oder Erfolgsversprechen. Ein Veröffentlichungsablauf lässt sich beispielsweise mit „Zum Einstieg“, „Mit Abstand“ und „Zum Schluss“ zeigen.
- Stimmen Beispiele nicht zum Artikel, passe sie an dessen tatsächlichen Kontext an. Ein Beratungsangebot braucht keine Kursbegriffe.
- Behalte die Anrede innerhalb eines Bildes bei. Für erklärende Skizzen reichen oft neutrale Beschriftungen ohne Anrede.
